# i18n — Bahasa Indonesia / English

Tanggal: 2026-08-29. Status: disetujui.

## Konteks

Budgetin saat ini menampilkan string UI hardcoded (campuran EN/ID) di 16 file
`src/**/*.tsx`, ±176 string. Pengguna ingin bisa memilih bahasa **English
(default)** atau **Bahasa Indonesia**, diubah dari halaman Settings.

## Pendekatan

Hand-rolled (tanpa dependency baru) — keputusan setelah membandingkan ukuran
bundle/RAM/CPU dengan react-i18next; untuk 2 bahasa bedanya tidak signifikan.

## Arsitektur

- `src/i18n/en.ts`, `src/i18n/id.ts` — kamus flat `{ key: string }`, shape
  **identik** antara kedua bahasa.
- `src/i18n/index.ts` — `t(lang, key)` = `dict[lang][key] ?? dict.en[key] ??
  key`, plus `validateKeys()` yang dijalankan saat dev/build agar key-set en/id
  selalu identik (key yang lupa terjemah ketahuan, bukan jadi bug diam-diam).
- `BudgetContext` — state `language` (default `'en'`, init dari localStorage
  `budget_lang`), `setLanguage(lang)` yang persist ke localStorage, dan helper
  `t(key)` diekspos lewat `useBudget()` (tanpa context baru / plumbing tambahan).

## Data flow

1. `setLanguage('id')` → simpan `budget_lang` di localStorage → re-render.
2. Komponen memanggil `t('settings.language')` → lookup kamus aktif → string
   ditampilkan. Fallback en → key.

## Perubahan file

- **Baru:** `src/i18n/en.ts`, `src/i18n/id.ts`, `src/i18n/index.ts`
- **Ubah:** `src/context/BudgetContext.tsx` (state + t), `src/components/views/SettingsView.tsx` (baris Language), dan 14 file komponen lain: ganti string hardcoded → `t('...')`.
- **Tanpa perubahan backend/DB/schema.** Bahasa adalah preferensi tampilan.

## Scope / di luar scope

- Masuk: semua string UI yang terlihat pengguna (nav, tombol, judul, label,
  modal, pesan, Settings).
- Di luar: format mata uang (tetap `Rp`), format angka/tanggal, pluralisasi,
  aksesibilitas `lang` attribute (defer), reverse proxy/cookie, multi-user.
- **Upgrade path** (`ponytail:`): kalau kelak >2 bahasa atau butuh pluralisasi
  rumit, pindah ke i18next — kamus flat ini mudah dimigrasi (key sudah tetap).

## Testing

- `npm run lint` (tsc) + `npm run build`.
- Self-check `validateKeys()` di kamus (unit, via build).
- Verifikasi UI Playwright: ganti bahasa di Settings → string berubah →
  persist setelah reload.

## Keputusan pengguna

- Default bahasa: **English**.
- Switch hanya di **Settings** (bukan header).
- Pendekatan: **hand-rolled**.
